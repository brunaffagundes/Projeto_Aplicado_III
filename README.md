## 📌 Sobre o Projeto

Este projeto tem como objetivo desenvolver um **sistema de recomendação de filmes** utilizando técnicas de **filtragem baseada em conteúdo** e o conjunto de dados **TMDB 5000 Movies Dataset** (Kaggle).  

Ao longo das quatro etapas, foram aplicadas práticas de:

- Engenharia e limpeza de dados  
- Análise exploratória (EDA)  
- Vetorização textual  
- Cálculo de similaridade  
- Avaliação do modelo  
- Documentação científica  
- Entrega de artefatos e apresentação final  

---

## 🎯 Objetivo Principal

Este trabalho propõe o desenvolvimento e avaliação de um sistema de recomendação de filmes utilizando o conjunto de dados TMDB 5000 Movie Dataset (Kaggle).

# 📊 Resultados Obtidos

As principais análises e visualizações incluem:

- Distribuição de gêneros  
- Top 10 filmes mais votados  
- Top 10 filmes mais populares  
- Boxplot das notas  
- Relação entre orçamento, receita e popularidade  
- Métrica **Precision@5** para avaliar a relevância das recomendações  
- Recomendações geradas a partir do modelo baseado em conteúdo  

**O protótipo demonstrou recomendações coerentes e alinhadas ao contexto semântico.**
